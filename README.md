# lm-bench

Sparkium CPU renderer implementation benchmark.

- `main` contains the benchmark workspace before the CPU renderer is implemented.
- `test` contains the completed CPU renderer and the validated evaluation result.

Clone with dependencies:

```bash
git clone --recurse-submodules https://github.com/LazyJazz/lm-bench.git
```

The evaluation configuration, scene data, converged references, and scoring implementation are included in the repository.
